Browser-based security tools, no account needed

Pigeon generates cryptographically random passwords, passphrases, PINs and usernames directly in your browser using crypto.getRandomValues. No data is ever sent to a server, stored in a database, or shared with third parties.

How to generate a strong password

Select your desired length (16+ characters recommended), enable uppercase, lowercase, numbers and symbols, then click Generate. The entropy meter shows strength in bits — aim for 80+ bits for important accounts.

Is my data safe?

Yes. Generation happens entirely in memory on your device. You can verify this by opening the browser's network inspector — no outgoing requests are made during generation. The full source code is available on GitHub.
